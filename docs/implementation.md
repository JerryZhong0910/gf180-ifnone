# Conversion and runtime responsibilities

The [examples](examples.md) show the concrete changes. The selected representation is called **GF180-ARC-PAIR-1**: ordinary input-edge paths qualified by explicit scalar predicates, with each supplied output-delay field assigned through its producer/Liberty identity.

## What the Python tools own

| Component | Responsibility |
|---|---|
| [intake.py](../tools/intake.py), [liberty.py](../tools/liberty.py) | Read original declarations, every SDF occurrence and raw Liberty groups; classify target/ordinary paths and authenticate required writer identities |
| [convert.py](../tools/convert.py) | Emit predicate nets, edge paths and ordered one-field target children; preserve ordinary records and synchronize renamed conditions |
| [verify.py](../tools/verify.py) | Independently derive membership, cone structure, edge/slot ownership and unchanged text from source inputs; check emitted text before accepting generator metadata |
| [prepare.py](../tools/prepare.py) | Authenticate inputs, prepare each case, expose the file-based entry and generate complete diffs and source/record/field maps |
| [assess.py](../tools/assess.py), [run.py](../tools/run.py), [run_annotation.py](../tools/run_annotation.py), [run_mixed.py](../tools/run_mixed.py), [run_carry.py](../tools/run_carry.py) | Compile, annotate, observe, compare independent expected events, and require effective negative controls |
| [references.py](../tools/references.py) | Compare the single committed reference set, or explicitly regenerate it after a passing run |

Each original conjunction becomes a `wand` driven by scalar `===` comparisons. A `wor` combines those exact binary matches; `membership === 1'b0` enables the endpoint fallback. Empty membership yields unconditional edge paths. The original helper evaluates the logic; the predicates affect timing paths only.

All declarations sharing a selected output are checked. On the owned paired-edge groups, each conditional declaration becomes two edge children. Collateral mux data groups keep one simple path per declaration and receive the same explicit predicate representation. This preserves the selected endpoint-local fallback policy without invoking destination-wide legacy `ifnone` selection. Addf carry paths and all functional helper bodies stay unchanged. Each helper's module declaration is renamed to match the behavioral wrapper, as shown in its case diff.

Generated nets occupy separate readable lines. The verifier reads syntax and unchanged byte spans, reconstructs every cone independently, and measures generated locations after parsing. Source line numbers identify the original statements; they do not dictate output formatting. The regression suite checks single-line source declarations, expanded cone formatting and rejected corruption of membership, collateral paths, untouched carry text and field bindings.

The public file-based reader classifies each occurrence from its source endpoint structure. A target record needs an authenticated Liberty identity for each supplied field; an ordinary record uses its original declaration match set. Ordinary conditions follow renamed collateral predicates, while the original IOPATH leaf, numeric tokens, empty slots and record order remain intact. Untouched addf carry records are emitted unchanged. A record map accounts for every input occurrence and its output lines. Unknown input forms fail explicitly.

The independent checker reconstructs the generated path relation from the source model, checks raw Liberty endpoints, condition, sense and timing type, and derives expected SDF text before checking emitter metadata. Hashes authenticate the inputs; condition and edge/slot checks establish their relationship. The mixed regression includes an authentic but wrong-condition Liberty owner, lost ordinary records, unsynchronized conditions and conflicting input edges. ## What fixed upstream Icarus owns

Status checked **2026-11-13**: all PRs below are merged, and their merge commits are included in the official source pinned by [build.sh](../tools/build.sh), [`5b9ce29`](https://github.com/steveicarus/iverilog/commit/5b9ce29b41d6af30e6ccb6e178d3ed2a71974e69). These are source-commit guarantees; use the fixed build to reproduce the results, rather than assuming an installed Icarus release contains them.

The contributions separate two problems: identifying the path to annotate, and delivering an event with the selected delay. The [public upstream selection](../tests/upstream.list), run by `make check-upstream`, exercises the following behaviors without PDK inputs:

| Technical problem | Upstream improvement | Use or check in this repository |
|---|---|---|
| A matching scalar SDF `COND` was skipped, leaving the model's default delay. | [#1713](https://github.com/steveicarus/iverilog/pull/1713) carries a local scalar condition's source identity through compilation and matches it with instance, endpoints and input edge. Annotation works even when the condition is false at annotation time. | Generated named predicates in addf, mux4 and mixed mux2 use this binding. Selected `sdf_cond_scalar`, `sdf_cond_edges`, `sdf_cond_partial`, `sdf_cond_multimatch`, escaped-name and rejection tests check the ordinary annotation interface. |
| Comparison and compound conditions need distinct identities after optimization. | [#1718](https://github.com/steveicarus/iverilog/pull/1718) adds local scalar `==` comparisons to explicitly sized unsigned one-bit 0/1 constants and ordered `&&` trees; [#1755](https://github.com/steveicarus/iverilog/pull/1755) adds ordered `\|\|` trees. Operand order and grouping remain part of the identity; vlog95 retains the source expression. | `sdf_cond_expr_*`, `sdf_cond_vlog95` and all four `sdf_cond_or_*` entries exercise these forms. Converted GF180 conditions use named predicates; OR expression matching is checked by the upstream fixtures, not by those converted cells. |
| An unchanged GF180 carry condition uses `===`, which did not bind even when SDF and model agreed. | [#1771](https://github.com/steveicarus/iverilog/pull/1771) adds scalar case-equality comparisons to the same one-bit constants, including leaves in ordered AND/OR trees, distinct from `==`. | An edge path with no matching input history could compete with a real edge at time zero. | [#1704](https://github.com/steveicarus/iverilog/pull/1704) excludes an edge-qualified source until its first matching transition, distinguishing missing history from a real zero-time event. | `modpath_timezero_edge` checks the initial rise, first fall and next rise. The GF180 cell fixtures score events after initialization and settling. |
| A canceled pulse's pending callback could deliver a later request at the old time. | [#1714](https://github.com/steveicarus/iverilog/pull/1714) separates scalar transaction values/delivery times and detaches canceled transactions, preserving cancellation when rearming. | `modpath_pulse_asymmetric` and `modpath_pulse_values` check asymmetric rearming, boundary pulses, separated four-state values and zero-delay behavior. The [recorded fixed-tool execution](validation.md#commands-and-results) passed all 23 native entries. The additional COND-only vlog95 run had eight successful simulations and twelve expected translation compile errors; it includes the 32-event case-equality fixture. Those results describe that selected execution, not every behavior supported upstream.

Existing upstream `vpi_get_delays` / `vpi_put_delays` processing preserves omitted fields in partial writes. The [mixed example](examples.md#convert-target-and-ordinary-records-together) reads back successive ordinary writes and measures the resulting events. Upstream condition binding does not choose GF180 fallback membership or infer a producer's field ownership: those remain converter and checker responsibilities. In particular, #1771 fixes carry-condition binding, not edge-sensitive `ifnone`. The converter's accepted condition and record forms remain those in [scope](scope.md#check-your-input), even where upstream accepts more syntax.

These increments were submitted by JerryZhong0910 and merged by Icarus maintainer Cary R., building on Icarus's existing compiler, SDF and VVP infrastructure. #1713 identifies the GF180 example as its motivating use case; #1771 isolates the carry binding issue. #1718 cites earlier timing-aware GLS identity work, and #1714 links the research implementation it adapts. Their PRs document the individual changes and validation, separately from this repository's model policy.

### Local initialization and observation

The [initial-annotation patch](../patches/initial-annotation.patch) modifies `vpi/sys_sdf.c`. It supplies `$sdf_annotate_initial`, rejects calls after time zero, requires exactly one match for a named conditional path through that entry, and prints effective two-slot readback in verbose mode. Earlier writes remain observable if a later named path is missing. Standard `$sdf_annotate` retains upstream multiple-match and later-annotation behavior. Condition identity and event scheduling come from the fixed upstream source.

The demo calls the initial entry while inputs are unknown, then releases the first stimulus at 1 ns. The custom task's time check does not itself order other time-zero active events; the bench supplies that ordering. This patch is an example harness facility; general SDF error supervision needs a separate interface. [Build instructions](examples.md#build-environment) authenticate the fixed source and patch; [validation](validation.md) records their execution.
